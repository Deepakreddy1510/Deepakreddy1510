## 🚀 Featured Projects

### 📄 PDF RAG Assistant — Multi-Document Retrieval-Augmented Generation

A multi-document **Retrieval-Augmented Generation (RAG)** system designed to let users upload PDF documents, ask natural-language questions, and receive answers grounded in the uploaded content with source citations.

- Built a **page-aware PDF ingestion and chunking pipeline** for preserving document context and page-level traceability.
- Generated semantic embeddings using **BAAI/bge-small-en-v1.5** and stored vectors in **PostgreSQL + pgvector**.
- Benchmarked retrieval strategies and selected **Dense Retrieval + CrossEncoder reranking** as the V1 production path.
- Achieved **Hit@5 = 1.000** and **MRR = 1.000** in retrieval evaluation.
- Used **Groq / Gemini** for grounded answer generation with document and page citations.
- Added refusal behavior when the uploaded documents do not contain enough evidence to answer a question.
- Built an interactive **Streamlit** interface for document upload, indexing, retrieval, and question answering.
- Structured the project for reproducible local development using **Docker** and PostgreSQL.

**Tech:** `Python` · `PostgreSQL` · `pgvector` · `BGE Embeddings` · `CrossEncoder` · `Groq` · `Gemini` · `Streamlit` · `Docker`
